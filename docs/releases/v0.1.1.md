# CC MiMo Rescue v0.1.1

## 简体中文

- 新增 Sparkle 更新通道，App 菜单提供 `Check for Updates...`。
- 发布包改为 ad-hoc 签名，并保持稳定 bundle identifier 以便后续更新保留 macOS 权限状态。
- 新增可复现发布脚本，生成版本化更新 ZIP、兼容安装 ZIP、DMG、appcast 和 SHA256 校验文件。
- README 改为 DMG 优先安装说明，并补充校验值、更新方式、依赖和 Gatekeeper 说明。

本版本仍未使用 Apple Developer ID 签名，也未 notarize。请只从官方 GitHub Release 下载，并在首次打开前核对 SHA256。

## English

- Added a Sparkle update channel with `Check for Updates...` in the app menu.
- Release builds are ad-hoc signed with a stable bundle identifier so future updates can preserve macOS permission state.
- Added a reproducible release script that creates a versioned update ZIP, compatibility install ZIP, DMG, appcast, and SHA256 checksums.
- Updated README installation guidance for DMG-first installs, checksum verification, updates, dependencies, and Gatekeeper behavior.

This build is still ad-hoc signed and is not Apple notarized. Download only from the official GitHub Release and verify the SHA256 checksum before first launch.
